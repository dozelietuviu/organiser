# Organiser

A personal organiser you open from your phone: food and calorie tracking (barcode scan, Open Food Facts shop products, your own foods, recipes and meal cards), trainer targets from a Google Sheet, workouts, weigh-ins with weekly averages, tasks and Google Calendar.

- Runs free on GitHub Pages and works offline.
- All data stays on the phone (localStorage). Use Settings → Backup to download a copy.
- No build step: plain HTML, CSS and JavaScript.
